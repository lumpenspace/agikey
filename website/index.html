⚿ DUAL API ARCHITECTURE

The Two API Modes & Real-Time SSE

Seamless support for both modern chat arrays and raw text completions

01

Chat Completions Mode

POST /v1/chat/completions

Accepts standard multi-turn conversation arrays [{ role, content }]. Automatically extracts system prompt and passes conversational context to the underlying agent CLI.

curl -N http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "agy",
    "messages": [
      {"role": "system", "content": "You are a code optimizer."},
      {"role": "user", "content": "Optimize this binary tree search."}
    ],
    "stream": true,
    "reasoning_effort": "high"
  }'
02

Text Completions Mode

POST /v1/completions

Accepts raw single-string or prompt array input. Ideal for code-completion plugins, legacy LLM clients, and benchmarking harnesses.

curl http://127.0.0.1:8000/v1/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "agy",
    "prompt": "def quicksort(arr):\n    if len(arr) <= 1: return arr\n",
    "max_tokens": 400,
    "stream": false
  }'
⚿ INTEGRATION SNIPPETS

Drop-In Client Compatibility

Use existing OpenAI libraries without changing your application code

app.py 
from openai import OpenAI

# Initialize client targeting Agikey local gateway
client = OpenAI(
    base_url="http://127.0.0.1:8000/v1",
    api_key="agikey"  # any placeholder key accepted
)

# 1. Real-time streaming chat completion
stream = client.chat.completions.create(
    model="agy",  # or "claude", "grok", "codex", "gemini-3.8-flash-high"
    messages=[
        {"role": "system", "content": "You are a concise engineer."},
        {"role": "user", "content": "Explain merge sort in 2 sentences."}
    ],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
index.ts 
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://127.0.0.1:8000/v1',
  apiKey: 'agikey',
});

// Stream tokens as they arrive
const stream = await openai.chat.completions.create({
  model: 'agy',
  messages: [{ role: 'user', content: 'Say hello in 3 languages.' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}

⚿ COMMAND LINE REFERENCE

Simple, Powerful CLI

A single portable tool with zero external dependencies

agikey discover
Performs deep system discovery for Claude Code, agy, Grok, and Codex. Probes versions, flags, models, and saves configuration to ~/.agikey/discovery.json. Add --json for machine output.
agikey serve
Starts the local OpenAI HTTP gateway and interactive web dashboard at http://127.0.0.1:8000. Loads from cache in ~20ms. Flags: -p, --port, -h, --host, -k, --key.
agikey check
Prints a clean ASCII diagnostic status report of all 4 agents in your terminal. Use --refresh to bypass cache.
agikey models
Lists all available OpenAI model IDs mapped across all discovered local CLI tools.
agikey chat "<prompt>"
Sends a prompt directly through the CLI with live token streaming to stdout. Example: agikey chat -m agy "Write quicksort".
agikey clear-cache
Removes the local discovery cache file from ~/.agikey/discovery.json.
