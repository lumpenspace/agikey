The Two API Modes & Streaming

Complete compatibility with both modern chat frameworks and legacy completion tools

API Mode 1

Chat Completions API

POST /v1/chat/completions

Standard multi-turn message format accepted by all modern LLM SDKs, LangChain, Cursor, and Continue.

{
  "model": "agy",
  "messages": [
    {"role": "system", "content": "You are a senior engineer."},
    {"role": "user", "content": "Write a debounce function in TypeScript."}
  ],
  "stream": true,
  "reasoning_effort": "high"
}
API Mode 2

Text Completions API

POST /v1/completions

Legacy single-prompt endpoint for code completion, older tools, and prompt benchmarking.

{
  "model": "agy",
  "prompt": "Complete this: function binarySearch(arr, target) {",
  "max_tokens": 500,
  "stream": false
}
∿ Real-Time SSE Streaming

Server-Sent Events (SSE) Built-in

Toggle stream: true on any endpoint to receive native chunks formatted identically to OpenAI's chat.completion.chunk wire format, ending with data: [DONE].

data: {"id":"chatcmpl-...","choices":[{"delta":{"content":"function"}}]}
data: {"id":"chatcmpl-...","choices":[{"delta":{"content":" search"}}]}
data: [DONE]

Drop-In SDK Integration

Change one line of code in your existing client: point base_url to your local Agikey port

main.py 
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8000/v1",
    api_key="agikey"  # any placeholder key
)

# Real-time streaming chat completion
stream = client.chat.completions.create(
    model="agy",  # or "claude", "grok", "codex"
    messages=[{"role": "user", "content": "Explain async/await in Python"}],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
index.ts 
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://127.0.0.1:8000/v1',
  apiKey: 'agikey',
});

const stream = await openai.chat.completions.create({
  model: 'agy',
  messages: [{ role: 'user', content: 'Say hello in 3 languages!' }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}

CLI Command Reference

Simple, single-binary CLI tool with intelligent caching

Command Description Example
agikey discover Deep discovery of all installed CLIs, versions, and capabilities; caches to ~/.agikey/discovery.json. agikey discover --json
agikey serve Starts the local HTTP server & interactive web dashboard on port 8000. agikey serve -p 8000
agikey check Fast diagnostic status check (reads instantly from cache in ~20ms). agikey check --refresh
agikey models Lists all accessible OpenAI model IDs across all installed tools. agikey models
agikey chat Send a test prompt directly from your terminal. agikey chat -m agy "Hello"
agikey clear-cache Deletes the local discovery cache file. agikey clear-cache
